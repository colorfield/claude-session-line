# session-line

Claude Code mod that pins a status line under the prompt.

`ctx 42% 84k/200k  ·  opus 5.5 · high  ·  ⎇ main (worktree)  ·  5h 63%  ·  $1.23`

Rate-limit windows show from 50% used; a toast suggests `/compact` at 85% context.

## Install

In Claude Code:

```
/plugin install session-line --marketplace colorfield/claude-session-line
```
